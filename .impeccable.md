# LEMARQUE — Design Context

This file captures the design context for the LEMARQUE storefront so design/polish
work stays consistent without re-litigating brand basics on every task.

## Design Context

### Users
Prospective buyers and collectors of a manufactured 1/1 luxury fashion label,
browsing on both mobile (Instagram-referral, casual scroll) and desktop
(considered browsing, higher intent). Price is "upon request" - this is not a
self-serve e-commerce checkout flow, it's an editorial lookbook that drives
inquiries.

### Brand Personality
Dark, editorial, exclusive. Straight from the site's own copy:
"Manufactured 1/1 Attire. Every piece handmade, unique, and irreplaceable."
"Handmade. Price Upon Request." Three words: **dark, exacting, rare.**

### Aesthetic Direction
- Theme: dark (near-black backgrounds, white/muted-white type) across the
  entire site — this is already fully established, not a per-page choice.
- Brand display font: "Arial Black" (`--font-brand`), used uppercase with
  wide tracking for collection names and page headings (e.g. "MALUM", "XXV").
  This is an existing, sitewide decision — do not swap it wholesale without
  an explicit request. Tracking/size should be tuned per-context instead
  (e.g. long product names need less letter-spacing than short collection
  names, so they don't wrap awkwardly).
- Body font: Inter (`--font-sans`).
- Layout: full-bleed editorial photography, generous negative space,
  minimal chrome, uppercase tracked-out labels (`text-[10px] uppercase
  tracking-[0.2em]` and similar) for eyebrows/nav/meta text.
- Motion: understated (fade/slide reveals via Framer Motion), no bounce/
  elastic easing.
- Anti-reference: nothing playful, no rounded/soft "SaaS card" aesthetic,
  no bright colors, no gradients as decoration.

### Design Principles
1. Photography is the hero. Chrome (nav, labels, buttons) stays minimal and
   gets out of the way of the imagery.
2. Full-bleed / edge-to-edge layouts on marketing pages — avoid centered
   content with visible dead air on the sides on wide viewports.
3. Wide letter-spacing reads as "luxury" for short labels/names, but must be
   dialed back for longer strings so text doesn't wrap into a ragged block.
4. Every new asset (hero photos, OG images) should extend the same visual
   world already established per collection, not introduce a new mood.

### Quality Bar
Flagship / production - this is a live commercial brand site, not an MVP.
